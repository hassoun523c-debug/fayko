# فايكو | Fayko

منصة تواصل اجتماعي عربية قيد التطوير باستخدام Flutter/Dart وخادم Node.js مع PostgreSQL.

## الموجود حالياً

- تطبيق Flutter بواجهة عربية RTL، وشاشة تسجيل الدخول وإنشاء الحساب.
- تكامل برمجي مبدئي مع API للمصادقة واستعادة الجلسة وحفظ رمز الدخول في تخزين آمن.
- خلاصة المنشورات النصية مرتبطة بالكود الخاص بالخادم: تحميل المنشورات، نشر منشور، الإعجاب وإلغاء الإعجاب، قراءة التعليقات وإضافتها.
- ملف شخصي يعرض معلومات الحساب مع تعديل الاسم والنبذة وتسجيل الخروج.
- تصنيفات اهتمامات عربية/عالمية يمكن حفظها بالحساب (رياضة، ألعاب، ديني، تعليم، تصاميم، تقنية، أخبار، وغيرها)؛ ترتيب المحتوى حسب الاهتمامات ما زال لاحقاً.
- شاشة بحث عن المستخدمين من API، مع متابعة وإلغاء المتابعة وفتح محادثة مباشرة.
- دردشة نصية مباشرة مرتبطة بالخادم: إنشاء المحادثات، حفظ الرسائل، سجلّ الرسائل، عدد غير المقروء والتحديثات اللحظية عبر Socket.IO عند اتصال الخادم.
- خادم API أولي وقاعدة PostgreSQL لمستخدمين ومنشورات وإعجابات وتعليقات ومتابعة.
- واجهات API للبحث عن المستخدمين وعرض ملفاتهم والمتابعة وإلغاء المتابعة.
- اختبارات Flutter وNode مكتوبة، وتضم اختبارات تكامل تستخدم PostgreSQL في CI؛ نتيجة النجاح الفعلية ما زالت غير مؤكدة.
- مسارات CI تفحص الكود والاختبارات فقط؛ لا تبني APK.

## الحالة الحالية — مهم

هذا **ليس تطبيقاً مكتملاً بعد**. تمت إضافة ربط المصادقة والخلاصة والدردشة النصية والاتصال اللحظي في الكود، لكن لم يتم تأكيد نجاح اختبارات CI أو تشغيل التطبيق والخادم معاً على جهاز أندرويد فعلي. إعداد Android لم يُولّد ويُختبر بعد باستخدام Flutter tooling.

لم يُنشأ APK في هذه المرحلة، عمداً. تمت إضافة قالب نشر مؤقت، لكن نشر الخادم لم يُنفّذ بعد ويحتاج إلى حساب Render وربط المستودع. كما أن شاشة الريلز تحفظ التصنيفات فقط؛ رفع وتشغيل الفيديوهات الفعلية والتوصيات لم تكتمل. يشمل العمل المتبقي التحقق الفعلي ونشر خادم HTTPS، رفع الصور والفيديو، إشعارات الهاتف والمكالمات، التشفير الطرفي، الأمان والخصوصية والإبلاغ والحظر، تجديد الجلسات واستعادة الحساب، مزامنة حالات القراءة والتسليم بشكل شامل، وتحسينات إضافية للملف الشخصي، إلى جانب اختبارات فعلية على أجهزة أندرويد.

## تشغيل بيئة التطوير

1. ثبّت Docker مع Compose وFlutter stable.
2. من مجلد `backend` انسخ `.env.example` إلى `.env` وبدّل `JWT_SECRET` بقيمة عشوائية قوية.
3. شغّل `docker compose up --build` من مجلد `backend`.
4. شغّل Flutter مع عنوان API المحلي المناسب للمحاكي:
   `flutter run --dart-define=FAYKO_API_BASE_URL=http://10.0.2.2:4000/api/v1`

عنوان `10.0.2.2` مخصص لمحاكي Android للوصول إلى الجهاز المضيف؛ ليس عنوان إنتاج ولا عنواناً مضموناً لهاتف فعلي. قبل استعمال هاتف أو نشر عام، يجب تجهيز عنوان خادم HTTPS قابل للوصول وتحديده عبر `FAYKO_API_BASE_URL`.

## التقنية الحالية

- Flutter / Dart للعميل.
- Node.js 22 وExpress 5 للخادم.
- PostgreSQL للبيانات.
- تخزين وسائط وفيديو متكيف ضمن مراحل لاحقة.

## أمان المستودع

لا تضع كلمات مرور أو مفاتيح API أو مفاتيح توقيع داخل المستودع. ملف `backend/.env.example` قالب فقط؛ لا ترفع ملف `.env` الحقيقي.
