# فايكو | Fayko

منصة تواصل اجتماعي عربية قيد التطوير.

## التقنية
- Flutter وDart للواجهة متعددة المنصات.
- دعم العربية واتجاه RTL.
- تصميم يدعم الوضع الداكن والفاتح.

## مراحل العمل
1. تأسيس بنية Flutter ودعم العربية.
2. بناء التنقل والواجهات الأساسية.
3. إضافة الحسابات والملفات الشخصية والمنشورات.
4. إعداد الخادم وقاعدة البيانات.
5. إضافة المحادثات والوسائط والإشعارات.
6. الاختبار وتجهيز إصدار Android.

## الحالة
المشروع في مرحلة التأسيس. تُنفذ الميزات تدريجياً مع الاختبار. لا تضع كلمات مرور أو مفاتيح API داخل المستودع.
