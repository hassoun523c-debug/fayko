# فايكو | Fayko

منصة تواصل اجتماعي عربية قيد التطوير باستخدام Flutter/Dart وخادم Node.js مع PostgreSQL.

## الموجود حالياً

- هيكل أولي لواجهة Flutter عربية باتجاه RTL.
- تنقّل مبدئي بين الرئيسية والريلز والدردشة والملف الشخصي؛ أقسام الريلز والدردشة والملف الشخصي ما زالت غير موصولة بوظائفها النهائية.
- خادم API أولي مع تسجيل حساب ودخول وتعديل الملف الشخصي.
- قاعدة PostgreSQL للحسابات والمنشورات والإعجابات والتعليقات والمتابعة.
- واجهات API للمنشورات النصية والإعجابات والتعليقات.
- اختبارات وحدة للخادم واختبارات واجهة أساسية مكتوبة؛ ننتظر تأكيد نجاح تشغيلها في CI.
- خطة تنفيذ هندسية ومقارنة موثقة للمنافسين.

## وثائق المشروع

- [خطة التنفيذ الرئيسية](docs/MASTER_PLAN.md): قائمة العمل المرجعية من التأسيس حتى الإطلاق.
- [دراسة المنافسين والخطة الاستراتيجية](docs/COMPETITIVE_ANALYSIS.md): مقارنة عشرة منتجات، دروس التصميم والهندسة، المخاطر، مؤشرات النجاح وخارطة طريق مبدئية.
- [الخادم وواجهات API](backend/README.md): الإعداد المحلي، المسارات المتاحة وحدود المرحلة الحالية.

## الحالة الحالية — مهم

هذا ليس تطبيقاً مكتملاً بعد. تطبيق Flutter **لم يُربط حتى الآن** بخادم API، كما أن الخادم لا يتضمن بعد رفع الصور والفيديو، والمحادثات، والمكالمات، والإشعارات أو النشر الإنتاجي. لا تعتبر الميزات المذكورة في خارطة الطريق منجزة ما لم تُنفّذ وتُختبر فعلياً.

لم يُنشأ APK في هذه المرحلة، عمداً. يقتصر عمل CI الحالي على الفحوصات والاختبارات، وليس بناء ملف تثبيت.

## التقنية الحالية

- Flutter / Dart للعميل على Android؛ تجهيز منصات Android والتحقق منها ما زال مطلوباً.
- Node.js 22 وExpress 5 للخادم.
- PostgreSQL للبيانات، مع مخطط أولي للحسابات والمنشورات والإعجابات والتعليقات والمتابعة.
- تخزين وسائط ومقاطع فيديو متكيفة ضمن مراحل لاحقة.

## أمان المستودع

لا تضع كلمات مرور أو مفاتيح API أو مفاتيح توقيع داخل المستودع. ملف backend/.env.example قالب فقط؛ أنشئ backend/.env محلياً وبدّل القيم السرية قبل تشغيل الخادم.
