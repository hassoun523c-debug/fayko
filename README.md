# فايكو | Fayko

منصة تواصل اجتماعي عربية قيد التطوير باستخدام Flutter وDart.

## الموجود حالياً
- هيكل أولي لواجهة عربية باتجاه RTL.
- تنقّل مبدئي بين الرئيسية والريلز والدردشة والملف الشخصي.
- ثيم داكن حقيقي وخيار ثيم فاتح في إعدادات الثيم.
- خطة تنفيذ هندسية ومقارنة موثقة للمنافسين.

## وثائق المشروع
- [خطة التنفيذ الرئيسية](docs/MASTER_PLAN.md): قائمة العمل المرجعية من التأسيس حتى الإطلاق.
- [دراسة المنافسين والخطة الاستراتيجية](docs/COMPETITIVE_ANALYSIS.md): مقارنة عشرة منتجات، دروس التصميم والهندسة، المخاطر، مؤشرات النجاح وخارطة طريق مبدئية.

## الحالة الحالية
هذه بداية الواجهة فقط، وليست منصة مكتملة بعد. لم يُربط التطبيق بخادم أو حسابات أو قاعدة بيانات، ولم يتم بناء التطبيق واختباره باستخدام Flutter tooling حتى الآن. ستُنفذ الميزات تدريجياً مع الاختبارات.

## التقنية المخطط لها
- Flutter / Dart للواجهة على Android وiOS.
- Backend باستخدام NestJS أو Go بعد تثبيت قرارات التصميم.
- PostgreSQL للبيانات الأساسية، مع تقييم مخزن منفصل للرسائل عند الحاجة.
- تخزين وسائط سحابي وبث فيديو متكيف ضمن مراحل لاحقة.

## أمان المستودع
لا تضع كلمات مرور أو مفاتيح API أو مفاتيح توقيع داخل المستودع.
